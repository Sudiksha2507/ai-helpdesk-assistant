# AI Helpdesk Assistant

A Python-based helpdesk application that helps users troubleshoot common technical issues using a searchable knowledge base.

## Features

- Interactive helpdesk interface
- Knowledge-base based issue retrieval
- MySQL database integration
- Troubleshooting knowledge base
- Offline operation without external API keys
- Streamlit web interface

## Tech Stack

- Python
- Streamlit
- MySQL
- SQL
- Git & GitHub
